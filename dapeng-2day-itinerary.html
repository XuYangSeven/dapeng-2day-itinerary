修改会自动保存在本机

点击左侧行程卡片或下方列表进入编辑；地图选点后再点“保存修改”。本机保存后，可用下方 GitHub 同步保存到仓库。

地图搜索服务检测中…

搜索默认就能用：免密钥走 OpenStreetMap 检索，并内置 48 个大鹏 / 深圳常用地点，无需任何配置。
想让结果更准（小店、民宿等新地点），或去掉底图上那条「鉴权失败」提示，可再填一次自己的腾讯地图 Key：
① 打开 lbs.qq.com → 控制台 → 应用管理 → 我的应用 → 创建应用；
② 在应用里「添加 Key」，勾选 WebServiceAPI 与 Web端(JS API)（两个都要勾）；
③ 把生成的 Key 粘到上面的输入框，点「保存并应用」，页面会自动刷新。
Key 只存在本机浏览器，不写进网页也不进仓库。域名白名单可填 xuyangseven.github.io（填了就只能在该域名用），留空则不限来源。Key 只存在当前浏览器，不写入网页也不进入仓库；在 WorkBuddy 预览里打开时本机自带地图服务，无需 Key。

GitHub 同步未连接

不填 Token 也能查看：打开页面会自动从公开仓库读取最新行程（只读）。要保存修改，需创建 GitHub Fine-grained Token，仅授予本仓库 Contents: Read and write 权限，粘贴后即生效；Token 只存在当前浏览器，不写入网页或仓库。填写后编辑内容会停止输入约 1 秒自动保存到本机并同步到 GitHub 的 data/itinerary.json，换手机打开同一链接即可查看与继续修改。
写入必须能连上官方 api.github.com：出现「同步失败（已存本机）」说明请求根本没到达 GitHub（与 Token 无关，Token 错会显示 401/403），内容已存本机，换 Wi-Fi 或移动网络后点「同步到 GitHub」即可补传。读取在官方不可达时会自动改用镜像通道，点「连接诊断」可逐条确认。
