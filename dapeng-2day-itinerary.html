编辑行程

修改会自动保存在本机

重要：本机数据的存放位置跟"打开页面的地址"绑定。在 WorkBuddy 预览面板里打开时，地址是 127.0.0.1:随机端口，每次重开端口都会变，浏览器会把它们当成不同网站——所以上次在预览里填的内容，这次打开就看不到了。
要长期保存，任选一种：① 用固定的线上地址 xuyangseven.github.io/dapeng-2day-itinerary 打开再编辑；② 在下面填 GitHub Token，改动会自动同步进仓库；③ 点「导出数据」把 JSON 存到网盘 / 发给自己，随时「导入数据」还原。
本机会自动保留最近 8 个版本快照，误覆盖时点「回退上一版本」即可找回；每次保存也都会写入本机，不必手动刷新。

地图搜索服务检测中…

搜索默认就能用，且只会给出深圳的地点：在线走 OpenStreetMap（免密钥），并内置 164 个深圳 / 大鹏常用地点（逐条核对过坐标），结果里带「内置精确点」标记的会优先显示。检索限定深圳靠的是行政区字段（而不是经纬度范围），所以像虎门、松山湖、凤岗、惠州澳头这些贴着边界的同名地点会被过滤掉，同时深圳大鹏新区自己那个「澳头」不会被误伤；底图上原有的鉴权提示条也已自动隐藏，无需处理。
想让检索覆盖更全（小店、新开民宿等），可再填一次自己的腾讯地图 Key（可选）：
① 打开 lbs.qq.com → 控制台 → 应用管理 → 我的应用 → 创建应用；
② 在应用里「添加 Key」，勾选 WebServiceAPI 与 Web端(JS API)（两个都要勾）；
③ 把生成的 Key 粘到上面的输入框，点「保存并应用」，页面会自动刷新。
Key 只存在本机浏览器，不写进网页也不进仓库；域名白名单可填 xuyangseven.github.io（填了就只能在该域名用），留空则不限来源；在 WorkBuddy 预览里打开时本机自带地图服务，同样无需 Key。

GitHub 同步未连接

不填 Token 也能查看：打开页面会自动从公开仓库读取最新行程（只读）。要保存修改，需创建 GitHub Fine-grained Token，仅授予本仓库 Contents: Read and write 权限，粘贴后即生效；Token 只存在当前浏览器，不写入网页或仓库。填写后编辑内容会停止输入约 1 秒自动保存到本机并同步到 GitHub 的 data/itinerary.json，换手机打开同一链接即可查看与继续修改。
写入必须能连上官方 api.github.com：出现「同步失败（已存本机）」说明请求根本没到达 GitHub（与 Token 无关，Token 错会显示 401/403），内容已存本机，换 Wi-Fi 或移动网络后点「同步到 GitHub」即可补传。读取在官方不可达时会自动改用镜像通道，点「连接诊断」可逐条确认。
